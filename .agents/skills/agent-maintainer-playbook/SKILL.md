Follow the repository playbook before and during issue work:

- Read and apply [/docs/wiki/Agent-Maintainer-Playbook.md](../../../docs/wiki/Agent-Maintainer-Playbook.md).
- Keep scope tied to issue acceptance criteria and verify with explicit evidence.
- Preserve release-baseline fidelity, profile separation, approval boundaries, and secret protections.
- Use exact-head independent review expectations for handoff and verdict labeling.

If any instruction conflict appears, follow system/developer/user hierarchy and treat the playbook as repository guidance.
