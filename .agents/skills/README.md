# Repository maintenance skill

Use [agent-maintainer-playbook](agent-maintainer-playbook/SKILL.md) when taking a GBH issue from triage through implementation,
PR verification, or release-candidate evidence. The skill routes to maintained project guidance; the
[canonical workflow](../../docs/wiki/Agent-Maintainer-Playbook.md) owns delivery policy.
Use `npm run maintenance -- task start`, `triage`, and `pr readiness` for registered worktree setup and current read-only evidence reports; see [tools](../../tools/README.md#agent-maintenance-workflow).
