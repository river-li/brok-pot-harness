Connect to your server

Your Bots, model credentials, skills, and Box workspace stay on the server. Open its SSH tunnel, then enter the local Gateway address and token.

The authenticated SSH tunnel must forward the Gateway and both Box display ports.
Use the same ports as the server's published ports. Default SSH forwarding uses 6180 and 6181.
Gateway and Box display traffic use the authenticated SSH tunnel. This app will not start Docker or a local Host. When connected, supported Mac tools can use this computer through the existing Host permission and approval controls.
