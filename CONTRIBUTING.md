# Contributing

Contributions to tool adapters, setup, documentation, and tests are welcome.

Start with the [maintainer workflow](docs/wiki/Agent-Maintainer-Playbook.md) for issue intake, work ownership, implementation, review, and merge.
It links to the [issue forms and triage rules](docs/wiki/Issue-Triage.md), [Development](docs/wiki/Development.md), and
[source recovery](docs/wiki/Source-Recovery.md). The repository and scoped AGENTS.md files define the constraints for the code you change.

For executable task setup and evidence reports, see the [maintenance CLI](tools/README.md#agent-maintenance-workflow). It creates a registered linked worktree from current main and provides read-only issue/CI triage and PR readiness reports.

Use the [package map](packages/README.md) and [Architecture](docs/wiki/Architecture.md) to find the right module.
The [installation guide](docs/wiki/Build-Guide.md) explains how to run GBH locally. New README and Wiki content is in English;
keep translations in separate language-suffixed files. Submit only sanitized diagnostics, and preserve upstream licensing and provenance.
